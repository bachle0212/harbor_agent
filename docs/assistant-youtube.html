How do I add a YouTube video?
G OptiBot Grounded in File Search
To add a YouTube video to OptiSigns, follow these steps:
  • Log in to the OptiSigns portal, navigate to Files/Assets, and click Apps.
  • Select the YouTube app.
  • Enter a Name for the asset.
  • Paste the video link into the URL field (if using YouTube Shorts, change /shorts/ in the link to /watch?v=).
  • Toggle closed captions on or off as needed, then click Save.
